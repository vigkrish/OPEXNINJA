# OPEX Ninja Launch Pack

This is an overlay pack for the existing `vigkrish/OPEXNINJA` repository.

Upload/replace the files at the same paths. It:
- Repositions the site as operational excellence consulting.
- Adds the 3-stage OPEX Ninja Method.
- Replaces the outdated AI-platform service messaging.
- Adds a lead-generation health-check form using the existing `/api/contact` endpoint.
- Removes fake contact details and marks them as placeholders.
- Adds GitHub Pages deployment workflow.
- Fixes Vite production minification and project-page base path.
- Updates SEO metadata and repository README.

Important:
1. Replace YOUR_EMAIL, YOUR_PHONE, YOUR_LOCATION and YOUR_LINKEDIN_URL.
2. Set VITE_API_URL if the API is deployed separately.
3. If using a custom domain, use VITE_BASE_PATH=/ instead of /OPEXNINJA/.
